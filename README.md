# 🌐 Skipp Website

Site do **Skipp**, um bot para Discord desenvolvido com foco em diversão, economia e ferramentas para servidores.

Este repositório reúne os arquivos-fonte do site, disponibilizados publicamente para consulta e utilização.

## 📢 Status do projeto

<badge color="danger">Descontinuado</badge>

Infelizmente, o site foi descontinuado devido à falta de orçamento para manter os custos de hospedagem.

Apesar do encerramento, o código-fonte continuará disponível neste repositório para quem quiser consultá-lo, estudá-lo ou utilizá-lo, respeitando os termos da licença.
